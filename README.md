# rohansolse.github.io

The root of `https://rohansolse.github.io/` — a plain index page linking to the
projects hosted under this subdomain.

It also exists so the subdomain root can be verified in Google Search Console:
drop the `google<token>.html` file Search Console gives you next to
`index.html`, push, and verify. That property covers every project page under
`rohansolse.github.io`, which is what a Safe Browsing review needs.
